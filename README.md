# SWE2
SWE 2 Projekt - Flip And Learn

## Anleitung zum ausführen des Vue-Projekts
#### Frontend
> cd ./frontend/flipandlearn\
> npm install\
> npm run serve\

läuft lokal i.d.R. dann auf http://localhost:8080 (siehe Konsolenausgabe)

#### Backend
> cd ./backend\
> npm install\
> npm run start\

läuft lokal i.d.R. auf http://localhost:3000 (siehe Konsolenausgabe)


## Regeln zu Git Commits
- in Englisch
- kurz und knapp (add, change, create, update, delete, etc.)
- mit Kennung von Task aus Jira, also #SCRUM-XX am Ende angefügt


## Konventionen
#### Namenskonvention Frontend
Vue-Komponenten: PascalCase
CSS-Klassen und IDs: kebab-case

#### Style Frontend
befolgt dem Prinzip von Mobile-First
