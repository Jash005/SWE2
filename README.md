# SWE2
SWE 2 Projekt - Flip And Learn

## Regeln zu Git Commits
- in Englisch
- kurz und knapp (add, change, create, update, delete, etc.)
- mit Kennung von Task aus Jira, also #SCRUM-XX am Ende angefügt

## Frontend Starten
> cd /SWE2/FRONTEND/flipandlearn

#### Testumgebung:
> npm run serve

#### Produktionsumgebung:
> npm run build
> ...

läuft lokal i.d.R. dann auf http://localhost:8080

#### Namenskonvention Frontend
Vue-Komponenten: PascalCase
CSS-Klassen und IDs: kebab-case

#### Style Frontend
befolgt dem Prinzip von Mobile-First


## Backend starten
> cd /SWE2/BACKEND

#### Testumgebung:
> npm run dev

#### Produktionsumgebung:
> npm run start
> 

läuft lokal auf http://localhost:3000
